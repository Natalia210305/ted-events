# TED Events - Εφαρμογή Διαχείρισης Εκδηλώσεων

Ολοκληρωμένο πληροφοριακό σύστημα διαχείρισης εκδηλώσεων και έκδοσης ηλεκτρονικών εισιτηρίων, υλοποιημένο με αρχιτεκτονική 3-Tier, Express Backend, React Frontend και Prisma ORM συνδεδεμένο σε Cloud PostgreSQL (Supabase).

## Χαρακτηριστικά & Zero-Configuration
Για τη διευκόλυνση της ακαδημαϊκής αξιολόγησης, η εφαρμογή παραδίδεται προ-ρυθμισμένη με Live Cloud Sandbox περιβάλλον. Η βάση δεδομένων φιλοξενείται ήδη στο Supabase, επομένως **ΔΕΝ απαιτείται** τοπική εγκατάσταση PostgreSQL, pgAdmin ή η χειροκίνητη εκτέλεση SQL scripts. Η εφαρμογή εκτελείται ακαριαία με μηδενικό setup (Zero-Configuration).

## Οδηγίες Εγκατάστασης και Εκτέλεσης

### 1. Προετοιμασία Φακέλου
Αποσυμπιέστε το αρχείο της εργασίας (`.zip`) και ανοίξτε το τερματικό σας στον κατάλογο του project.

### 2. Εκκίνηση Backend Server
Ανοίξτε ένα τερματικό, πλοηγηθείτε στον φάκελο του backend και εγκαταστήστε τις εξαρτήσεις:
```bash
cd backend
npm install

Το αρχείο .env περιλαμβάνεται ήδη έτοιμο στον φάκελο backend με το live DATABASE_URL του Supabase και το JWT_SECRET.

Εκκινήστε τον server: 
npm start
Ο διακομιστής θα εκκινήσει στη θύρα 3000 και θα συνδεθεί αυτόματα live στην Cloud PostgreSQL.

Ανοίξτε ένα νέο (δεύτερο) παράθυρο τερματικού, πλοηγηθείτε στον φάκελο του frontend και εγκαταστήστε τις εξαρτήσεις:
cd frontend
npm install
Εκτελέστε την εφαρμογή σε περιβάλλον ανάπτυξης (Vite):  
npm run dev
Ανοίξτε τον browser σας στη διεύθυνση που θα εμφανιστεί στο τερματικό (συνήθως http://localhost:5173).
